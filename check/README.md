# 보안 설정 점검표

10번 논문 「금융권과 중앙행정기관 웹사이트의 보안 설정 비교: 보안 헤더와 구버전 TLS 차단을 중심으로」(류인수, 2026)의 결과를 쓰는 앱입니다.

> 이 앱은 금융·공공 웹사이트 담당자가 우리 사이트의 보안 설정을 논문의 6개 항목으로 채점하고, 금융 53곳·공공 50곳과 비교해 무엇부터 고칠지 알려 줍니다.

- 공개 주소: https://whoisinsu.github.io/mypage/check/
- 파일: `index.html` 하나 (HTML·CSS·JS가 모두 들어 있음)

## 실행 방법

설치할 것은 없습니다. 아래 둘 중 하나를 고르세요.

1. `index.html`을 더블클릭해 브라우저(Chrome, Edge, Firefox, Safari)로 엽니다.
2. 또는 이 폴더에서 `python -m http.server 8000`을 실행하고 http://localhost:8000/ 을 엽니다.

인터넷이 없어도 동작합니다. 인터넷이 없으면 글꼴만 기본 글꼴로 바뀝니다.

## 사용자가 할 일 세 가지

1. **정보 넣기**: 메인 페이지의 응답 헤더를 붙여 넣고, ① HTTPS 강제와 ⑥ 구버전 TLS 차단 여부를 고릅니다. 처음이라면 「예시 1」이나 「예시 2」를 누릅니다.
2. **결과 보기**: 논문의 핵심 항목(⑥ 구버전 TLS 차단) 결과, 통신 보안(①·⑥) 2점·보안 헤더(②~⑤) 4점 점수와 금융·공공 평균 비교, 항목별 적용률을 봅니다.
3. **고칠 순서 확인**: 빠진 항목을 고칠 순서와 설정 예시를 확인하고 「결과를 글로 복사」를 누릅니다.

## 데이터와 비밀값

- 예시 1~3은 가상의 사이트입니다(`.test` 도메인). 실제 기관을 측정한 값이 아닙니다.
- 개인정보는 넣지도, 저장하지도 않습니다. 입력은 브라우저 안에서만 계산하고 어디에도 보내지 않습니다.
- AI 서비스 키 같은 비밀값을 쓰지 않습니다. 필요한 환경 변수는 **없습니다**.

## 한계

논문과 같이 메인 페이지 하나에서 헤더가 있는지만 봅니다. 헤더 값이 올바른지는 평가하지 않습니다. 이 앱은 사이트에 직접 접속하지 않으므로 ①과 ⑥은 사용자가 확인해 답해야 합니다.

점수는 메인 페이지에 접속할 때 드러나는 보안 설정 6개(응답 헤더 4개와 HTTPS·TLS 연결 설정 2개)가 있는지만 센 것이지, 사이트가 얼마나 안전한지가 아닙니다. 공격을 실시간으로 탐지해 막는 장치(XDR)나 웹 방화벽처럼 서버 안쪽의 방어는 점수에 나타나지 않습니다.
